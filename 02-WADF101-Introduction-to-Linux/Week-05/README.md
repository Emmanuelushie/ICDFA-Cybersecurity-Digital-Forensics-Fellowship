## 📘 Overview

This folder contains the practical work completed during Week 05 of Introduction to Linux. Labs 21–24 cover Z shell use, shell configuration, file globbing, and safe file manipulation. The documentation is structured for academic assessment and professional GitHub portfolio presentation.

## 📘 Week 05 Learning Areas

### Lab 21: Using the Shell
Shell identification, listing, navigation, paths, and history.  
📑 `Lab21_UsingTheShell_Report.md`

### Lab 22: Configuring the Shell
Z shell configuration, variables, aliases, and configuration reload.  
📑 `Lab22_ConfiguringTheShell_Report.md`

### Lab 23: File Globbing
Asterisk, question mark, character classes, negation, brace expansion, and wildcard copying.  
📑 `Lab23_FileGlobbing_Report.md`

### Lab 24: File Manipulation
Creation, redirection, copying, moving, renaming, and deletion.  
📑 `Lab24_FileManipulation_Report.md`

## 🧪 Tools and Environment
