# Week 01: Linux Setup, Shell Fundamentals and Filesystem Navigation

This folder contains the hands-on laboratory work completed during Week 01 of
the Linux Essentials module at the International Cybersecurity and Digital
Forensics Academy (ICDFA).

The week focused on establishing a functional Linux laboratory environment,
developing confidence with the command line, using built-in Linux
documentation, navigating the filesystem, exploring important system
directories, and practising safe file management.

The documentation is structured for both academic submission and
professional GitHub portfolio presentation, with command evidence,
explanations, findings, and dedicated spaces for screenshot verification.

---

# 📘 Week 01 Learning Areas

## Lab 1: Linux Setup & Shell Fundamentals

This lab covers the initial Linux environment setup and core terminal skills.

Topics covered:
- Linux virtual machine validation
- System and kernel identification
- Disk and storage verification
- User and shell identification
- Working with command exit status codes
- Command history and evidence export
- Built-in command help and manual pages
- man, --help, help, apropos, and whatis
- Identifying built-in and external commands

📑 Lab Report:
Lab01_LinuxSetup_ShellFundamentals_Report.md

---

## Lab 2: Filesystem Navigation

This lab focuses on understanding and navigating the Linux filesystem safely.

Topics covered:
- Absolute and relative paths
- Directory creation and navigation
- Filesystem tree discovery
- Linux system directory exploration
- Directory permissions and ownership
- File creation and hidden files
- File discovery with find
- File identification with file
- Safe deletion and workspace hygiene

📑 Lab Report:
Lab02_FilesystemNavigation_Report.md

# 🎯 Learning Outcomes

By completing Week 01, I developed practical ability to:

- Verify a Linux installation and understand basic system information.
- Navigate the command line using common Bash commands.
- Interpret command exit status codes.
- Locate reliable command documentation directly from Linux.
- Distinguish between built-in shell commands and external commands.
- Work with absolute and relative filesystem paths.
- Understand the purpose of major Linux system directories.
- Create, search, identify, and safely remove files.
- Maintain a controlled workspace for cybersecurity laboratory activities.
- Document technical work using reproducible commands and visual evidence.

These skills provide the Linux foundation required for later cybersecurity,
network security, security operations, and digital forensics activities.

# 🔐 Evidence and Safety

All exercises were performed in a controlled virtual laboratory environment.

- System exploration was performed without intentionally modifying critical system files.
- File creation and deletion activities were restricted to the designated practice workspace.
- A VirtualBox snapshot was created as a recovery point.
- Screenshots are used as evidence of practical execution.
- Commands are documented so the work can be reviewed and reproduced.
